# Context: Lab C Phase 1 — Hybrid BiomeScatterSystem (Corrected Architecture)

โปรเจกต์ Marooned กำลังเปลี่ยนจาก "Ragnarok Online (Tile-based)" เป็น "Don't Starve/Mad Island (Modular Scatter)"
**สำคัญ**: ต้องทำตาม convention ของโปรเจกต์เคร่งครัด — System ไม่แตะ GameObject, Data ผ่าน Luban, View เป็นคน Instantiate

# 🎯 Design Philosophy
- **Hybrid Approach**: Prefab Scatter + Random Offset (ไม่ใช่ Procedural Gen เต็มรูปแบบ)
- **Biome = Spawn Rules**: แต่ละ Biome มีชุด Prefab + Loot Table + Harvestable Nodes
- **Tool-Gathering Ready**: แยก HarvestableNode (ต้องใช้ tool) ออกจาก DecorativeProp (เดินผ่านได้)

# Architecture Constraints (เคร่งครัด)
- **Data Layer**: Luban CSV เท่านั้น (BiomeDef.csv, HarvestableNodeDef.csv)
- **System Layer**: Plain C#, ไม่เรียก Instantiate/Destroy โดยตรง — publish events ให้ View ทำ
- **View Layer**: MonoBehaviour, subscribe events แล้ว Instantiate/Destroy GameObject
- **ScriptableObject**: ใช้เฉพาะสำหรับ Prefab References (ลาก Prefab ใส่) — ชื่อ `BiomePrefabSet`
- VContainer: Resolve ผ่าน `GetComponentInParent<GameLifetimeScope>()`
- MessagePipe: ใช้ events สำหรับ communication ระหว่าง System ↔ View

## Step 3: BiomeScatterView.cs (MonoBehaviour — Instantiate/Destroy)
```csharp
public class BiomeScatterView : MonoBehaviour
{
    private BiomeScatterSystem _scatterSystem;
    private Dictionary<string, BiomePrefabSet> _prefabSets = new();
    private List<GameObject> _activeObjects = new();
    
    private void Start()
    {
        var scope = GetComponentInParent<GameLifetimeScope>();
        _scatterSystem = scope.Container.Resolve<BiomeScatterSystem>();
        
        // โหลด PrefabSets ทั้งหมด
        LoadPrefabSets();
        
        // Subscribe BiomeChangedMessage
        var subscriber = scope.Container.Resolve<ISubscriber<BiomeChangedMessage>>();
        subscriber.Subscribe(OnBiomeChanged);
        
        // Spawn Biome เริ่มต้น
        var playerLocation = scope.Container.Resolve<GameStateProvider>().GetPlayer().CurrentLocationId;
        _scatterSystem.SetBiome(playerLocation);
    }
    
    private void OnBiomeChanged(BiomeChangedMessage msg)
    {
        // Despawn ของเก่า
        ClearAll();
        
        // Instantiate ตาม SpawnsToCreate
        foreach (var spawn in msg.SpawnsToCreate)
        {
            var prefab = GetPrefab(msg.BiomeId, spawn.PrefabId, spawn.IsHarvestable);
            if (prefab != null)
            {
                var go = Instantiate(prefab, spawn.Position, Quaternion.identity);
                _activeObjects.Add(go);
                
                // ถ้าเป็น HarvestableNode → ติด HarvestableNodeComponent
                if (spawn.IsHarvestable)
                {
                    var component = go.AddComponent<HarvestableNodeComponent>();
                    component.Init(spawn.NodeId); // อ่านจาก HarvestableNodeDef.csv
                }
            }
        }
    }
    
    private void ClearAll()
    {
        foreach (var go in _activeObjects) Destroy(go);
        _activeObjects.Clear();
    }
}
```
